# 마지미 — 가비아 도메인 연결 안내

작성일: 2026-09-23

**목적:** 가비아에서 구매한 `mazimi.kr`을 마지미 Oracle 서버에 연결합니다.

## 전달받은 팀원이 할 일

가비아에서 아래 DNS 레코드 **3개**를 설정한 뒤, 설정 완료 사실을 개발 담당자에게 알려주세요. 임시 주소에서 운영 중인 서버를 정식 주소로 전환하는 작업은 개발 담당자가 진행합니다.

| 레코드 타입 | 호스트 | 값 / 위치 | TTL |
|---|---|---|---|
| A | `@` | `$MAZIMI_HOST` | 기본값 유지 |
| A | `www` | `$MAZIMI_HOST` | 기본값 유지 |
| A | `app` | `$MAZIMI_HOST` | 기본값 유지 |

- `@`는 `mazimi.kr`, `www`는 `www.mazimi.kr`을 뜻합니다.
- `app`은 사용자 앱 주소 `app.mazimi.kr`입니다. 대표 주소는 랜딩·관리자·API에 사용합니다.
- 값에는 숫자 IP만 입력합니다. `https://`, 도메인, 경로는 붙이지 않습니다.
- `www.mazimi.kr`은 서버 설정 후 `https://mazimi.kr`로 이동하도록 구성합니다.
- 별도 웹호스팅이나 SSL 상품을 구매할 필요는 없습니다.

## 1. DNS 설정 화면 열기

1. [가비아 홈페이지](https://www.gabia.com/)에 도메인 소유 계정으로 로그인합니다.
2. **My가비아 → 서비스 관리 → DNS 관리툴**로 이동합니다.
3. 목록에서 **mazimi.kr**을 찾습니다.
4. 도메인 옆 **설정** 또는 도메인을 선택한 후 **DNS 설정**을 누릅니다.

메뉴 이름은 화면 버전에 따라 조금 다를 수 있습니다. 가비아의 [DNS 레코드 설정 공식 안내](https://customer.gabia.com/manual/38/3041/3040)를 함께 참고하세요.

### 도메인이 없거나 수정할 수 없다면

- 도메인을 구매한 가비아 계정이 맞는지 확인합니다.
- 현재 네임서버가 가비아인지 확인합니다. Cloudflare 등 다른 업체의 네임서버를 쓰고 있다면 **실제 네임서버 업체에서 위 레코드를 설정**해야 합니다.
- 네임서버를 변경하면 기존 메일 등에도 영향을 줄 수 있으므로, 이 작업을 위해 네임서버 자체를 임의로 변경하지 않습니다.

## 2. A 레코드 입력하기

1. **레코드 추가**를 누릅니다.
2. 타입 **A**, 호스트 **@**, 값 **$MAZIMI_HOST**를 입력합니다.
3. TTL은 기본값으로 두고 **확인**을 누릅니다.
4. 한 줄을 더 추가해 타입 **A**, 호스트 **www**, 값 **$MAZIMI_HOST**를 입력합니다.
5. **확인**을 누른 뒤 화면 하단의 **저장**까지 누릅니다.
6. 타입 **A**, 호스트 **app**, 값 **$MAZIMI_HOST**도 추가하고 저장합니다.
7. 설정 화면을 다시 열어 세 레코드가 저장되었는지 확인합니다.

### 기존 레코드가 있다면

- 같은 호스트의 A 레코드가 이미 있다면 새 줄을 중복 추가하지 말고 기존 값을 수정합니다.
- `www`에 기존 CNAME이 있다면 A와 함께 둘 수 없습니다. 기존 연결 용도를 확인한 뒤 `www`를 위 A 레코드로 변경합니다.
- 다른 서버로 향하는 `@` 또는 `www`의 AAAA(IPv6) 레코드가 있으면 개발 담당자에게 알립니다. 일부 기기만 다른 서버로 접속하는 원인이 됩니다.
- **MX, TXT 및 다른 서비스의 레코드는 그대로 둡니다.** 메일이나 서비스 인증에 사용될 수 있습니다.

## 3. 담당자에게 완료 전달

아래 내용을 복사해 보내면 됩니다.

```text
mazimi.kr DNS 설정 완료했습니다.

A / @   / $MAZIMI_HOST
A / www / $MAZIMI_HOST
A / app / $MAZIMI_HOST

가비아에서 저장까지 완료했습니다.
설정 완료 시각: YYYY-MM-DD HH:MM (한국 시간)
기존 레코드 변경 또는 특이사항: 없음 / 내용 기재

서버 연결과 HTTPS 접속 확인 부탁드립니다.
```

비밀번호, 로그인 인증번호, 서버 접속 키는 전달하지 않습니다.

## 4. 설정 결과 확인하기

DNS 반영에는 시간이 걸릴 수 있습니다. 가비아는 네트워크 환경에 따라 최대 48시간까지 연결이 불안정할 수 있다고 안내합니다. [가비아 안내](https://customer.gabia.com/faq/detail/959/2183)

터미널을 사용할 수 있다면 다음을 실행합니다.

```bash
dig +short A mazimi.kr
dig +short A www.mazimi.kr
dig +short A app.mazimi.kr
```

세 결과 모두 `$MAZIMI_HOST`이면 DNS 연결이 반영된 것입니다.

Windows 명령 프롬프트에서는 다음 명령을 사용할 수 있습니다.

```bat
nslookup mazimi.kr
nslookup www.mazimi.kr
nslookup app.mazimi.kr
```

**DNS가 반영되어도 서버 배포·방화벽·인증서 설정이 끝나기 전에는 웹사이트가 열리지 않을 수 있습니다.** 이 경우 DNS를 반복해서 변경하지 말고 개발 담당자에게 확인을 요청합니다.

## 개발 담당자 확인 항목

- 세 도메인의 A 레코드가 `$MAZIMI_HOST`인지 확인합니다.
- Oracle 네트워크와 서버 방화벽의 TCP 80·443 연결을 확인합니다.
- 마지미 서비스와 Caddy가 정상 실행 중인지 확인합니다.
- 서버 `DOMAIN=mazimi.kr`, `APP_DOMAIN=app.mazimi.kr`로 전환합니다. Caddy의 `www` 대표 주소 이동 설정을 확인합니다.
- 앱의 API 주소·CORS·카카오 리다이렉트를 새 주소로 맞춥니다. 카카오에는 `https://mazimi.kr/api/v1/auth/kakao/callback`만 등록합니다(웹·앱 모두 API 로그인을 씁니다).
- 웹·앱을 새 API 주소로 재빌드한 뒤 HTTPS 인증서와 실제 로그인 복귀를 확인합니다.
- `https://mazimi.kr` 접속과 `https://www.mazimi.kr` → 대표 도메인 이동을 확인합니다.
- `https://app.mazimi.kr`에서 앱이 열리는지 확인합니다.
- 서버의 공인 IP가 변경되면 세 A 레코드를 함께 갱신합니다.

현재 문서는 **설정 안내**입니다. DNS 연결과 HTTPS 동작이 완료됐음을 의미하지 않습니다.

## Google 로그인도 함께 전환

Google 클라이언트 생성 후 승인된 리디렉션 URI에 `https://mazimi.kr/api/v1/auth/google/callback`을 등록합니다. 상세 절차는 [Google 로그인 설정](mazimi-google-login-setup.md)을 참고하세요. OAuth 콜백의 호스트는 API 도메인 `mazimi.kr`이며 앱 복귀 주소 `app.mazimi.kr/login`과 구분합니다.
