# 마지미 전체 점검 결과 — 2026-10-02

지역·추천 API, 모바일 상태·세션, 수집·신청·알림을 독립적으로 점검하고 발견한 결함을 수정했다. OCI의 API·워커·웹 배포와 기존 지역 데이터 복구를 완료했다. **부산 사용자에게 문제된 용인 공고가 노출되는 현상은 운영 API에서 해소됐음을 확인했다.** 실제 기기와 외부 로그인·기관 접수 검증은 아래 항목이 남아 있다.

팀원용 설치 파일과 웹 주소는 [테스트·인수인계 안내](../mazimi-team-guide.md)에서 확인한다. APK 링크는 해당 문서에서 관리한다.

## 무엇을 고쳤는가

| 영역 | 수정 결과 |
| --- | --- |
| 지역 필터 | 수집된 지역 정보의 누락을 전국 대상으로 오인하던 처리를 수정했다. 홈·탐색·추천에서 저장된 지역을 사용하고, 지역이 준비되지 않았을 때 전체 지역 요청으로 바뀌지 않도록 했다. |
| 학교 혜택 | 학교 미선택·다른 대학 사용자에게 교내 혜택을 추천하지 않는다. 학교 선택과 학적 조건을 확인하고, 대학 선택 해제 시 탭과 이전 학교 정보를 정리한다. |
| 로그인·개인 조건 | 이전 계정·게스트 초안이 현재 회원의 추천에 섞이지 않도록 했다. 동시 토큰 갱신, 로그아웃 뒤 늦은 응답, 서버 일시 장애, 신규 회원의 프로필 저장 오류를 수정했다. 닉네임도 저장한다. |
| 원본 디자인 | 원본 Figma의 초록 시작 화면·흰 로고, 온보딩·카드·아이콘·글꼴 규격을 적용했다. 화면의 금액·자격·접수 상태는 실제 데이터로 표시한다. |
| 기업 혜택 수집 | 승인된 수집의 일시 장애는 대기 후 자동 재시도한다. robots의 명시적 거부·권한 만료·새 도메인은 차단하며, 원문 조건 변경을 임의로 승인하지 않는다. |
| 알림 | 실제 기기 토큰과 공고 연결을 전달하고, 채널 선택·한국 시간 마감·하루 횟수 제한을 적용한다. 인앱 수신 거부와 발송 이력을 구분하며 로그에서 토큰·운영 키를 가린다. |
| 신청·만료 | 만료 혜택은 공개 목록에서 제외하되 신청 당시 공고·서류 목록·신청 이력을 보존한다. 동의·기관 권한·폼 변경·중복 제출·접수번호 검증을 확인했다. |
| Next 웹·관리자 | 늦게 도착한 이전 지역 응답과 이전 계정의 권한 응답을 폐기한다. 503 장애를 빈 목록이나 로그인 실패와 구분하고 재시도를 제공한다. |

## 운영 데이터 복구와 재확인

운영 공개 API에서 확인한 결과:

| 확인 | 결과 |
| --- | --- |
| 부산 + 용인 검색 | 0건 |
| 부산광역시 별칭 + 용인 검색 | 0건 |
| 경기 + 용인 검색 | 1건, 해당 공고 지역 `gyeonggi` |
| 부산 추천 | 문제된 용인 공고 없음 |
| 학교를 선택하지 않은 추천 | 교내 전용 혜택 없음 |
| API 준비 상태 | DB·스키마 정상 |

운영 지역 검증 기록(비공개)에 요청 결과를 남겼다. 검증은 공개 조회로 수행했으며 사용자 계정이나 기관 신청을 만들지 않았다.

기존 데이터는 일반 재정규화 5,808건 처리 후 지역만 갱신하는 빠른 배치로 남은 8,071건을 복구했다. 빠른 배치 실패는 0건이고 약 38초가 걸렸다. 일일 워커도 동시에 자료를 갱신했으므로 이 작업 건수의 합을 고유 공고 수로 해석하면 안 된다. 공고·원문 스냅샷의 정규화 버전 불일치는 0건이었다.

원문 신청 기간이 `20260601 ~ 20250710`으로 뒤집힌 온통청년 자료 1건은 검증에서 거부했다. 원문은 보존했고 공개 프로그램은 0건이다. 정부 혜택 1,676건은 지역 범위를 확정하지 못해 `unknown`으로 유지한다. 이 자료는 전체 탐색에서 확인할 수 있지만 내 지역·추천에서는 제외하며 전국 대상으로 확대하지 않는다. [데이터 복구 기록](production-region-backfill-20261002.json)

## 검증과 배포 상태

| 검증 | 결과 |
| --- | --- |
| Rust 전체 테스트 | 286개 통과, 실패 0개. 외부 API 키가 필요한 1개는 제외 |
| Rust 검사 | `cargo check`, 포맷, 전체 대상 clippy 통과 |
| 모바일 | TypeScript 검사, 세션 회귀 11개, 브라우저 6개 흐름 통과. 브라우저 오류 0개 |
| 원본 시작 이미지 | 생성기 10개 밀도·테마 조합 확인. 최종 APK의 시작 이미지 5개와 집 모양 아이콘 15개가 원본에서 생성한 이미지와 픽셀 단위로 일치 |
| Next 웹 | 빌드·ESLint 통과. 응답 역전·장애 복구·관리자 계정 전환 브라우저 검사 4개 통과 |
| OCI | API·워커·웹 배포 완료, migration `20261002000019` 적용 |

검증 상세는 [서비스 회귀 결과](service-regression-20261002.json)와 아래 독립 감사에 남겼다. JSON은 각 검사 시점의 기록이며 이후 배포·빌드 진행 상태는 이 문서와 팀 안내에서 갱신한다.

CI는 빈 DB에서 테스트 전에 마이그레이션하도록 수정했고, 실행 파일 테스트도 포함했다. 통합 테스트와 웹 lint 오류를 무시하던 설정을 제거했다. `9a21480` 실행의 모바일·DB 테스트·웹 검사는 통과했으나 Rust lint는 부동 `stable` 버전과 운영 컴파일러의 차이로 실패했다. 운영과 동일한 Rust `1.94.0`으로 고정한 **`9d8816b`의 CI 7개 작업은 모두 통과**했다. Rust·모바일·웹 검사와 API/워커/웹 Docker 빌드를 포함한다. [통과 기록](https://github.com/woominsung1116/mazimi/actions/runs/36961170148)

추가 집 모양 아이콘이 포함된 **Android versionCode 4 APK 빌드를 완료**했다. [팀 안내](../mazimi-team-guide.md)에 설치 링크·버전·검증 기록을 정리했다. 기존 APK는 서버 변경만 반영받으므로 화면·세션 수정까지 확인하려면 해당 안내의 최신 APK를 설치해야 한다.

## 실제 사용 전에 남은 확인

- **실제 Android 기기:** 설치·업데이트, OS 시작 화면, 앱 복귀·백그라운드 종료, 네트워크 단절·재접속, 실제 알림 수신을 확인해야 한다.
- **iOS:** `kr.mazimi.app` 설정과 1024px 불투명 아이콘은 준비했지만 서명된 iOS 빌드·TestFlight 배포·실기기 검증은 하지 않았다. Apple 개발자 계정과 App Store Connect 설정을 확인해야 한다. iPhone에서는 현재 웹 앱을 테스트할 수 있다.
- **외부 로그인:** 카카오 로그인·취소·딥링크 복귀를 실제 계정·기기에서 확인해야 한다. Google 로그인 활성화와 실제 성공은 이번 검증에 포함하지 않았다.
- **기관 신청:** 실제 기관의 연결 승인·API 키·권한 기한과 사용자 동의가 필요하다. 연결 테스트 통과가 실제 접수 성공을 의미하지 않는다. 접수 여부가 불명확하면 자동 재제출하지 않는다. 금융 계약은 기관의 인증·동의 절차에서 진행한다.
- **지역 조건:** 현재 필터는 시·도 단위다. 시·군·구 제한, 부모 거주지, 학교 소재지 등의 복합 조건은 상세 확인이 필요하다. 자유서술의 새로운 표현까지 완전히 해석한다고 보장할 수 없다.
- **자동화 범위:** 승인된 소스의 반복 수집·재시도·만료·오류 탐지는 자동화했다. 새 수집 권한 취득, 키 발급·회수, 기관 접수 계약, 실제 혜택 조건의 불명확한 변경은 담당자 확인이 남는다.
